Interpretation and provenance. These are situational assessment model estimates, not raw observed case counts or forecasts. A reporting vintage represents a particular analysis date. Revisions may reflect newly available data or updated estimates. The default demonstration dataset is synthetic. When external CSV files are configured, the application analyses those inputs. Source filenames are displayed beneath the charts. This is an independent research software demonstration, not affiliated with or endorsed by ACEFA.
